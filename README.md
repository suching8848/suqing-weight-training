## 制作与负重

在合成面板“负重带”分类制作，消耗 **干净碎布条×2＋石块×1＋木板×2**，无需额外工具或技能等级。原版石块实际ID为 `Base.Stone2`。

负重带本体重量 **10**。穿戴、存包与移动惩罚遵循原版负重规则：当前默认穿戴系数0.3，穿戴时约计入 **3** 负重；是否超重和减速由人物总负重及负重上限决定。本模组不额外施加固定减速，不改变全局穿戴折算系数或人物负重上限。

物品ID为 `SuQingWeightTraining.TrainingBelt`。独立穿戴槽允许普通腰带与胸挂继续共存。旧负重带只更新本物品的重量，保留原实例及其他数据，不进行全世界道具扫描。

本模组不主动添加锻炼疲劳或肌肉拉伤；获得训练经验也不会触发原版健身动作。严重超重仍可能按原版规则伤背，健身与战斗积累的酸痛也会正常保留。

## 移动训练

穿戴负重带并实际徒步移动，可训练 **体格、力量、冲刺、潜行、灵活、轻巧**。不要求附近有僵尸，也不要求采用对应技能的动作姿势。

每累计 **1游戏分钟**有效移动，六项技能分别结算经验。沙盒“训练经验倍率”默认 **1**，可调 **0.1–20**，支持小数。

| 有效移动游戏时间 | 默认倍率1：每项基础经验 |
| --- | ---: |
| 1分钟 | 5 |
| 10分钟 | 50 |
| 1小时 | 300 |

**每项基础经验＝有效移动游戏分钟×5×训练经验倍率。**

例如倍率0.1时，每分钟每项产生0.5点基础经验。随后交给原版经验系统，继续遵循全局/技能经验设置、人物特质和营养等修正；独立技能倍率与全局倍率的关系也遵守原版规则，本模组不重复手工计算。适用的独立蛋白饮料强化可继续作用于力量、体格；本模组不包含或强制依赖该饮料模组。

站立、顶墙无位移、乘车、睡眠、死亡和检测到的异常位置跳变不计训练。发奖按实际移动期间经过的 **游戏时间** 累计，不按行走距离计算。游戏加速随游戏时钟推进，暂停不计；未满1分钟的训练余数随角色保存，存读档不补发离线经验。每次结算使用当时的倍率和有效增益。满10级的技能不再发放经验，原版营养限制继续有效。

## 训练状态面板

每次进入存档时面板默认隐藏。右键实际负重带，选择“显示负重训练状态”打开，再次选择关闭。显隐只在本次游戏会话内有效。

面板显示当前倍率、训练或暂停状态、下次结算还需移动的游戏秒，以及六项技能最近的实际经验增量；满级或原版限制导致的0经验会分别标记。面板只读状态，不参与发奖或推进计时；显示组件故障不阻断训练回调。

## 图标与封面

0.3.2补充独立负重带物品图标、制作分类图标与模组封面。制作分类图标供支持分类图片的 **Neat Crafting** 界面使用；原版制作界面仍可通过“负重带”文字分类正常使用，Neat Crafting不是依赖。

封面延续蘇清的银白长发、淡紫眼睛、浅色龙角、浅紫龙翼与白色鳞片长尾设定，以负重训练为主题；封面不写游戏版本号。新增美术不改变角色穿戴外观或地面模型。

## 兼容与安装

运行包仅使用Lua及原版物品、配方、沙盒脚本，**没有自带Java、JAR、DLL或ZombieBuddy依赖**。本项目针对单人游戏制作，未声明多人兼容。

本地安装时，将发布包中的 `SuQingWeightTraining/` 放入游戏用户数据的 `mods/` 目录，在游戏中启用 `SuQingWeightTraining`。替换正在使用的本地模组前应正常退出游戏，并保留可恢复的旧运行包。不要混装旧Java实现。

禁用模组会停止训练，已通过原版系统获得的经验不会撤销。升级不需要恢复旧世界或重写存档沙盒参数。0.3.0起基准为每分钟5点，旧0.2.0为每分钟1点，因此同一数值设置对应产量为旧版的5倍。
